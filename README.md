# CodeAlpha Image Gallery

A responsive and interactive image gallery built with React, Vite, and Tailwind CSS as part of my CodeAlpha Front-End Development Internship.

## ✨ Features

- **Responsive Design:** Adapts to different screen sizes, including desktops, tablets, and mobile devices.
- **Category Filtering:** Browse images by Nature, Cities, People, Animals, and Technology.
- **Interactive Lightbox:** Click any image to view it in a larger overlay.
- **Image Navigation:** Navigate between images using the previous and next buttons.
- **Keyboard Support:** Press `Escape` to close the lightbox.
- **Modern UI:** Clean, dark-themed interface with yellow accents.
- **Reusable Components:** Built with React components for better organization and maintainability.

## 🛠️ Technologies Used

- React
- Vite
- Tailwind CSS
- JavaScript
- HTML5

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have Node.js and npm installed on your computer.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/CodeAlpha_ImageGallery.git
   ```

2. Navigate to the project folder:

   ```bash
   cd CodeAlpha_ImageGallery
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
